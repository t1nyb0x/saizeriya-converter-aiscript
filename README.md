# サイゼリヤ番号変換

サイゼリヤのグランドメニューの番号を入れると、どのメニューかを教えてくれる Misskey の AiScript App ウィジェットです。

```
2101 ミラノ風ドリア 300円（税込）
```

## 使い方

1. `npm install` のあと `npm run build` を実行し、`dist/widget.is` を作る
2. Misskey でウィジェット「AiScript App」を追加する
3. ウィジェットの設定を開き、`dist/widget.is` の中身をスクリプト欄に貼り付けて保存する
4. 番号を入れて「調べる」を押す

全角数字（例: `２１０１`）や前後の空白が入っていても検索できます。

AiScript 1.2.1（Misskey のフロントエンドと同じバージョン）で動作を確認しています。

## メニューデータ

- 出典: サイゼリヤ公式 メニューブック「グランドメニュー」(menu2606_j, 2026.06 A 版)
  - https://book.saizeriya.co.jp/library/site/menu1907/book-lists/
- 取得日: 2026-10-01
- 収録: 104件。価格は税込
- 番号は公式のページ画像から読み取りました。メニュー名と価格は、公式のテキストデータと照合しています
- デザートは「すぐに」と「あとで」で番号が分かれているため、別々に収録しています
- ワインの赤と白、生ビールのジョッキとグラスなど、メニュー上で1つにまとまっている商品は、区別できる名前を付けて収録しています
- 店舗によって取り扱いが異なる商品（ビーフステーキとラム（仔羊）のランプステーキなど）も収録しています

収録していないもの:

- ランチメニュー、朝サイゼメニュー、チキンステーキの別冊など、グランドメニュー以外のメニューブック

## メニュー改定時の更新

`src/menu.is` の `MENU` を書き換え、先頭コメントの出典と取得日を更新してください。そのあと `npm test` を実行して、データの形式とウィジェットの動作を確認します。

## 開発

```
src/menu.is      番号の対応表
src/lookup.is    番号の正規化・検索・表示文字列の組み立て
src/ui.is        ウィジェットの画面
build.mjs        src/*.is を連結して dist/widget.is を出力
test/            検索ロジックのテストと、Ui を模したウィジェットの統合テスト
```

ウィジェットにはスクリプトを1ファイルしか貼れないため、開発時はファイルを分け、`build.mjs` で連結しています。`dist/widget.is` は直接編集しないでください。

```
npm test   # ビルドしてからテストを実行
```
