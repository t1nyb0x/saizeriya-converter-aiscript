# サイゼリヤ番号変換

サイゼリヤのグランドメニューの番号をメニュー名に変換する、Misskey 用の AiScript です。次の2つがあります。

- **ウィジェット**: 番号を入れると、どのメニューかを教えてくれる AiScript App ウィジェット
- **プラグイン**: タイムラインのノートにある番号の後ろに、メニュー名を添えて表示するプラグイン

```
ウィジェット: 2101 ミラノ風ドリア 300円（税込）
プラグイン:   今日は 2101（ミラノ風ドリア）と 1202（小エビのサラダ）
```

## ウィジェットの使い方

1. `npm install` のあと `npm run build` を実行し、`dist/widget.is` を作る
2. Misskey でウィジェット「AiScript App」を追加する
3. ウィジェットの設定を開き、`dist/widget.is` の中身をスクリプト欄に貼り付けて保存する
4. 番号を入れて「調べる」を押す

全角数字（例: `２１０１`）や前後の空白が入っていても検索できます。

## プラグインの使い方

1. `npm install` のあと `npm run build` を実行し、`dist/plugin.is` を作る
2. Misskey の「設定 > プラグイン > プラグインのインストール」を開き、`dist/plugin.is` の中身を貼り付けてインストールする

ノートを表示する直前に、本文と CW の番号の後ろにメニュー名を添えます。リノート・引用元のノートも対象です。書き換わるのは自分の画面の表示だけで、ノートそのものは変更しません。

変換するのは、前後が数字や英字とつながっていない4桁の数字のうち、番号表にあるものです。関係のない4桁の数字（例: 「1401人」）でも、番号表にあればメニュー名が添えられます。次の場所にある数字は、リンクや書式が壊れないように変換しません。

- URL の中（`https://example.com/notes/2101`）
- ハッシュタグ・メンション・カスタム絵文字の中（`#2101`、`@user_2101`、`:emoji_2101:`）
- インラインコードとコードブロックの中

## 動作環境

AiScript 1.2.1（Misskey のフロントエンドと同じバージョン）で動作を確認しています。

## メニューデータ

- 出典: サイゼリヤ公式 メニューブック「グランドメニュー」(menu2606_j, 2026.06 A 版)
  - https://book.saizeriya.co.jp/library/site/menu1907/book-lists/
- 取得日: 2026-10-01
- 収録: 104件。価格は税込
- 番号は公式のページ画像から読み取りました。メニュー名と価格は、公式のテキストデータと照合しています
- デザートは「すぐに」と「あとで」で番号が分かれているため、別々に収録しています
- ワインの赤と白、生ビールのジョッキとグラスなど、メニュー上で1つにまとまっている商品は、区別できる名前を付けて収録しています
- 店舗によって取り扱いが異なる商品（ビーフステーキとラム（仔羊）のランプステーキなど）も収録しています

収録していないもの:

- ランチメニュー、朝サイゼメニュー、チキンステーキの別冊など、グランドメニュー以外のメニューブック

## メニュー改定時の更新

`src/menu.is` の `MENU` を書き換え、先頭コメントの出典と取得日を更新してください。そのあと `npm test` を実行して、データの形式とウィジェット・プラグインの動作を確認します。

## 開発

```
src/menu.is      番号の対応表
src/lookup.is    番号の正規化・検索・表示文字列の組み立て
src/ui.is        ウィジェットの画面
src/annotate.is  ノート本文中の番号にメニュー名を添える処理
src/plugin-meta.is  プラグインのメタデータ
src/plugin.is    プラグイン本体（ノート表示時の割り込み）
build.mjs        src/*.is を連結して dist/widget.is と dist/plugin.is を出力
test/            検索・変換ロジックのテストと、Misskey の API を模したウィジェット・プラグインの統合テスト
```

ウィジェットとプラグインにはスクリプトを1ファイルしか貼れないため、開発時はファイルを分け、`build.mjs` で連結しています。`dist/*.is` は直接編集しないでください。

```
npm test   # ビルドしてからテストを実行
```
